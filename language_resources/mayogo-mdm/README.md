# Mayogo (`mdm`)

Mayogo is the third Northern DRC selection, with **7,911 unique locally curated
French-aligned pairs** from an authentic DRC-labelled source. The package marks it copyrighted, so text remains local
and Git-ignored; metadata and the preparation script are published.
