# Ndo / Kebu (`ndp`)

Ndo is the fifth Northern DRC selection, with **7,943 unique locally curated
French-aligned pairs** from an authentic DRC/Uganda source. The edition is restricted, so its text remains
Git-ignored and only metadata and reproducibility scripts are published.
