# Bembe / Kibembe (`bmb`)

The Maniema track contains **2,984 unique French–Kibembe paragraph pairs**
from matching official editions of the same publication. The editions share
document IDs and paragraph IDs, providing deterministic structural alignment.

The authentic source is copyrighted. EPUB files and derived text are therefore
kept local and Git-ignored; the track is suitable for local evaluation but not
for redistribution.
