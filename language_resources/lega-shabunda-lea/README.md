# Lega-Shabunda (`lea`)

The Maniema track contains **30,703 unique French–Lega-Shabunda verse pairs**
from the complete official DRC edition *Mikanda Zili mu Idagi*.

Lega-Shabunda is kept explicitly separate from Lega-Mwenga (`lgm`). The source
is copyrighted, so all cached pages and derived text remain local and
Git-ignored.
