# Luba-Katanga / Kiluba (`lub`)

Do not mix Luba-Katanga/Kiluba (`lub`) with Ciluba/Tshiluba/Luba-Kasai
(`lua`). This track represents Southeastern DRC/Katanga.

## Curation status

The source contains 197,423 English--Kiluba rows from the MT560/OPUS
collection under CC BY 4.0. Normalization retains **197,411 unique non-empty
pairs**; only 12 rows are removed through empty/exact-pair filtering.

The tracked Parquet is the complete source artifact. Generated standard-schema
CSV and JSONL files remain local because they are large and reproducible.
