# Zande / Pazande (`zne`)

Zande is the first Northern DRC priority, with **30,865 unique locally curated
French-aligned pairs**. The authentic DRC/CAR/South Sudan edition is used. The package marks it as
copyrighted, so the text remains Git-ignored and only metadata and scripts are
published.
