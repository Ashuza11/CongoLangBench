# Nyanga / Kinyanga (`nyj`)

Search Kinyanga, “Nyanga language,” Inyanga, Banyanga, Walikale, `nyj`; exclude Nyanja (`nya`) and place-name noise.

## Curation status

The package can technically produce **3,192 Nyanga--French aligned verses**
from Matthew, Luke, John, and Colossians. Package metadata marks version 4564
public-domain, but no explicit open redistribution licence was confirmed from
the authoritative source page. The track is therefore
**evaluation-only/licence-verification-required** and its text is not published.
See the [source audit](metadata/source_audit.md).

## Verified and evaluated resources

- **CONVERTIBLE SOURCE — MONOLINGUAL/BIBLE — TERMS:** [YouVersion Kinyanga](https://www.bible.com/versions/4564-nyj-traduction-bilbe-en-kinyanga) is readable/app-downloadable, but no open corpus licence was verified. Contact the named publisher/rightsholder.
- **CONVERTIBLE SOURCE — MONOLINGUAL + LEXICON:** [kinyanga.com](https://kinyanga.com/) and its [reading/download page](https://www.kinyanga.com/fr/lecture) host translated Bible portions, stories, literacy materials, linguistic works, audio, and a vocabulary. The site permits ordinary downloads under unspecified “recognized norms,” not clearly bulk ML reuse; obtain written permission and item-level attribution.
- **CONTACT LEAD — LEXICON:** *Kinsonsomori kinyanga–français / français–kinyanga* by Mushunganya Sambukere was publicly announced in 2026. A book announcement is not a downloadable/open dataset; contact the author/publisher.

## Best sources you can use now

1. **DATA — VERSE-ALIGNED TEXT + AUDIO APP:** [Kinyanga avec audio](https://play.google.com/store/apps/details?id=com.kinyanga.goma.rdc) contains the Gospel of Luke with selectable **Kinyanga–French** or **Kinyanga–Swahili** side-by-side/verse-by-verse display and synchronized Kinyanga audio. This is the clearest ready-made parallel source, but app access is not an extraction licence; contact the support email shown on Google Play.
2. **DATA — WEB TEXT/DOWNLOADS:** [kinyanga.com reading page](https://www.kinyanga.com/fr/lecture) provides Luke, written stories, Bible stories, vocabulary/literacy material, and linguistic PDFs. Request written permission to crawl/download in bulk.
3. **DATA — BIBLE WEB/APP:** [2025 YouVersion Kinyanga Bible](https://www.bible.com/fr/versions/4564-nyj-traduction-bilbe-en-kinyanga), published by GAPLCDI/The Seed Company. Ask the publisher for USFM and reuse terms.
4. **CONTACT:** the [kinyanga.com project page](https://www.kinyanga.com/fr/projet) reports continuing Bible, dictionary, song, and story collections; these community files may be more valuable than public web pages.
