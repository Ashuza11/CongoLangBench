# Tabwa / Kitabwa (`tap`)

## Curation status

The public track contains **5,039 unique French--Tabwa verse pairs**. This is
the complete alignment exposed by package version 4387; it is not truncated to
the project's 1,500-pair minimum. Tabwa is the second selected language in the
Southeastern DRC/Katanga regional top five, after Kiluba.

The Tabwa edition is a DRC variety published by The Word for the World
International under CC BY-SA 4.0. It is aligned by verse key with the
public-domain French Louis Segond 1910 edition.

- [Source and alignment metadata](metadata/ebible_alignment.md)
- [Reproducible preparation script](scripts/prepare_ebible.py)
