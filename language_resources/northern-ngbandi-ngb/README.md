# Northern Ngbandi (`ngb`)

Northern Ngbandi replaces Lingala in the Northwestern regional top five so a
national-language track is not counted again as a local-language selection.
The authentic DRC/CAR-labelled edition provides **7,887 unique locally curated
French-aligned pairs**. Its text is restricted and therefore remains Git-ignored.
