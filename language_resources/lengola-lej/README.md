# Lengola (`lej`)

This Tshopo track contains **5,774 unique English--Lengola pairs**, extracting
all usable aligned verses from the open Lengola collection and pairing them
with the open English unfoldingWord Literal Text.

Both sources use CC BY-SA 4.0. The generated dataset is publishable under the
same licence with attribution retained in
[source metadata](metadata/open_pdf.md).
