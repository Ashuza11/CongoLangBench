# Kanyok (`kny`)

## Acquisition status

Kanyok / Kanyoka is a DRC-specific language of the Kasai--Lomami area and the
fifth language selected for the Kasai regional track. A complete 2008 Kanyok
Bible with Deuterocanon is documented under catalogue identifier `KNYFUL`, but
the catalogue currently provides no text, download link, publisher, or explicit
reuse licence.

No text is stored in this repository yet. The next action is to request:

1. a digital, verse-keyed copy of `KNYFUL`;
2. permission to use it for research and model evaluation;
3. explicit permission to redistribute the aligned Kanyok pairs; and
4. the required attribution and licence wording.
