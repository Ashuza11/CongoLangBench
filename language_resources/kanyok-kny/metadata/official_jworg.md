# Official jw.org Kanyok source

## Source identity

- Language: Kanyok / Kanyoka / Kanioka
- ISO 639-3: `kny`
- Country: Democratic Republic of the Congo
- Source site: jw.org
- Site language path: `https://www.jw.org/kny/`

## Located Bible books

The Kanyok site exposes an online New World Translation book set at:

`https://www.jw.org/kny/cilamin-cya-mikand/bibl/nwt/books/`

The following books are available there:

- Matewus / Matthew
- Mark
- Luuk / Luke
- Jah / John
- Myand yilongel bapostol / Acts
- Tiit / Titus
