# Fuliiru / Kifuliiru (`flr`)

Search Fuliiru, Fuliru, Kifuliiru, Kifuliru, Ibufuliiru, `flr`. The principal DRC area is Uvira Plain/Uvira Territory; “Uvira, Fizi” overstates Fizi as a core area.

## Curation status

The package produced **30,546 Fuliiru--French aligned verses** across 66 books.
The local evaluation track is curated and ready. Fuliiru version 2355 is marked
non-public-domain and the official edition is all-rights-reserved, so its raw
and processed text remains Git-ignored and is not published. See the
[source audit](metadata/source_audit.md).

## Verified and evaluated resources

- **DATA — MONOLINGUAL / CONVERTIBLE BITEXT — TERMS, ALL RIGHTS RESERVED:** [Kifuliiru Bible on eBible](https://ebible.org/Bible/details.php?id=flr), complete Bible with downloadable/readable formats. The edition says “All rights reserved”; obtain permission for corpus redistribution/training and align only after that.
- **DATA — LEXICON + SPEECH — TERMS / permission:** [Kifuliiru Public Dictionary](https://dictionary.kifuliiru.net/dictionary) provides multilingual glosses and native audio. Request a bulk export, licence, contributor consent, and version information.
- **CONTACT LEAD:** [Kifuliiru Lab](https://kifuliiru.org/) reports large lexical/audio/training holdings. Its totals are self-reported and the public site does not establish a downloadable, licensed corpus; do not count the figures as acquired data.
- **CONVERTIBLE SOURCE:** [fuliiru.com](https://www.fuliiru.com/fr) and community platforms contain documents/media; check each item’s creator and rights before collection.

## Best sources you can use now

1. **DATA — FOUR-LANGUAGE DICTIONARY + AUDIO:** [Kifuliiru Public Dictionary](https://dictionary.kifuliiru.net/dictionary) searches Kifuliiru, Swahili, English, and French and reports 1,000+ entries with community audio. Use it immediately for manual work; request the underlying export/licence from its maintainers.
2. **DATA — MONOLINGUAL TEXT/MEDIA:** [fuliiru.com](https://www.fuliiru.com/fr) explicitly offers Kifuliiru Bible, documents, audio/video, and downloads. Record item URLs/creators and request a corpus-wide permission.
3. **DATA — BIBLE:** [YouVersion Fuliiru](https://www.bible.com/fr/languages/flr) and [Scripture Earth `flr`](https://www.scriptureearth.org/00fra.php?idx=1344&iso_code=flr&language=Fuliiru) provide reading/audio access. The eBible edition is all-rights-reserved, so ask Wycliffe/the translation team for USFM and an ML/research licence.
4. **CONTACT:** [Kifuliiru Hub](https://www.kifuliiru.com/) centralizes dictionary, proverbs, learning, audio, and books; it is the strongest route to community-held datasets.
