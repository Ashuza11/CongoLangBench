# Yaka (`yaf`)

## Curation status

The public track contains **7,104 unique French--Yaka verse pairs**. This is
the complete alignment exposed by package version 3951 and is not truncated to
the project minimum. The package marks the edition public domain and associates
it with both the Democratic Republic of the Congo and Angola.

Yaka is a major language of southwestern DRC extending across the Angola
border. This source is retained as a DRC-relevant cross-border variety, not as
a DRC-exclusive edition. The Yaka text is aligned by canonical verse key with
the public-domain French Louis Segond 1910 edition.
