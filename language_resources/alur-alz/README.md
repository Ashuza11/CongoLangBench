# Alur / Dho-Alur (`alz`)

Alur is the first completed Ituri track. The open MT560 wrapper labels the
English–Alur data for the Democratic Republic of the Congo and releases it
under CC BY 4.0. All **7,567 unique pairs** are retained rather than truncated.
