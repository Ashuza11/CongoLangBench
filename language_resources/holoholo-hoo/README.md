# Holoholo (`hoo`)

The Maniema–Tanganyika transition track contains **1,531 unique
French–Holoholo verse pairs** from all officially available chapters of Mark,
Luke, and 1 Peter.

Holoholo is spoken in the DRC, but the official edition does not identify a
narrower regional subvariety. The source is authentic but copyrighted, so
cached and derived text remains local and Git-ignored.
