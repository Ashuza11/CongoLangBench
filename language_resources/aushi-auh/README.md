# Aushi (`auh`)

## Curation status

The open candidate track contains **1,900 unique French--Aushi verse units**:
Matthew (1,071), Mark (674), James (108), and 2 Thessalonians (47). All
available aligned rows are retained, and the track exceeds the project's
1,500-pair minimum by 400 pairs.

The source is an authentic CC BY-SA 4.0 Aushi edition provided by The Word for
the World International. Open.Bible identifies it as a Zambian edition. Since
Aushi is also spoken in southeastern DRC, this corpus is retained as a clearly
labelled cross-border candidate; it is not represented as a DRC-specific
variety.

## Source note

The Mark supplement was extracted from a 2025 Bible in Every Language PDF.
Four source units combine adjacent verse numbers (`9:44-45`, `9:46-47`,
`11:26-27`, and `15:28-29`); these are preserved as combined references rather
than split artificially. Before freezing the benchmark, compare the Zambian
edition with DRC Aushi usage or document community confirmation that the
cross-border variety is suitable for the intended evaluation.
