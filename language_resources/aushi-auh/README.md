# Aushi (`auh`)

## Curation status

The open candidate track contains **1,226 unique French--Aushi verse pairs**:
Matthew (1,071), James (108), and 2 Thessalonians (47). All available aligned
rows are retained. The track needs **274 additional pairs** to reach the
project's 1,500-pair minimum.

The source is an authentic CC BY-SA 4.0 Aushi edition provided by The Word for
the World International. Open.Bible identifies it as a Zambian edition. Since
Aushi is also spoken in southeastern DRC, this corpus is retained as a clearly
labelled cross-border candidate; it is not represented as a DRC-specific
variety.
