# Pende / Phende (`pem`)

## Acquisition status

Pende is a major DRC language of the Kwango--Kwilu area and the fifth language
selected for the Western DRC track. The project has not yet located an openly
licensed, downloadable Pende--French or Pende--English sentence corpus.

The search is not limited to religious material. It includes large multilingual
bitext collections, web-mined corpora, translation memories, humanitarian and
educational data, dictionaries with translated examples, and community or
government publications. Religious text is treated only as a fallback and is
not imported without clear reuse terms.

No Pende text is stored in this repository yet. See the source inventory for
the checked collections and the evidence needed before a source can be added.
