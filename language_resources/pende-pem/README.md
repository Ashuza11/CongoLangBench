# Phende / Pende (`pem`)

This Kasai/Kwilu transition track is built from the open Door43 Pende
varieties **Gipende Gungu** and **Gipende Ganga**, aligned to the English
unfoldingWord Literal Text by shared verse identifiers.

The source repositories are CC BY-SA 4.0 and credit ACTB (Association
Congolaise de la Traduction de la Bible) among the translators. The generated
bitext is publishable under the same licence with the attribution recorded in
[source metadata](metadata/door43_pende_composite.md).
