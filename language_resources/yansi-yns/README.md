# Yansi (`yns`)

## Curation status

The public track contains **7,951 unique French--Yansi verse pairs**. This is
the complete alignment exposed by package version 3929 and is not truncated to
the project minimum. The source registry labels the edition as DRC Yansi and
public domain.

The Yansi text is aligned by canonical verse key with the public-domain French
Louis Segond 1910 edition. Authentic source text is retained with Unicode and
whitespace normalization and exact-pair deduplication only.

- [Source and alignment metadata](metadata/package_alignment.md)
- [Reproducible preparation script](scripts/prepare_package.py)
- [Africa Corpus catalogue](https://huggingface.co/datasets/AfriSpeech/africa-corpus)

Generated standard-schema CSV and JSONL files remain local because they are
reproducible from the tracked raw alignment.
