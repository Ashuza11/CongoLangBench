# Lobala (`loq`)

Lobala is the fifth data-supported Northwestern DRC track, with **7,920 unique
locally curated French-aligned pairs**. Package edition 1294 is aligned locally with public-domain French. Because the Lobala edition
is marked copyrighted, all text remains Git-ignored; only metadata and the
reproducible preparation script are published.
