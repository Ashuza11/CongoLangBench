# Sanga / Kisanga (`sng`)

## Curation status

Sanga was investigated for the Southeastern DRC/Katanga shortlist. Its identity is
confirmed as Sanga (DRC), also called Kisanga, Luba-Sanga, or Southern Luba,
with ISO 639-3 code `sng`. It must not be confused with Sango (`sag`) or merged
with the closely related Luba-Katanga/Kiluba (`lub`).

No publishable bitext has yet been acquired. The source investigation found
evidence of a complete Kisanga Bible and smaller translated resources, but no
downloadable sentence-aligned corpus with explicit redistribution rights. The
`africa-bitext-builder` registry has no `sng` edition.

Because the current regional phase requires five usable bitext tracks, Sanga
has moved to the acquisition backlog and Bemba (`bem`) occupies the current
third Katanga slot. This does not remove Sanga from the project.

See [the source inventory](metadata/source_inventory.md) for the verified leads
and required acquisition action. No text from restricted or ambiguous sources
is stored in this repository.
