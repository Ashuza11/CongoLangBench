# Zimba (`zmb`)

The Maniema track contains **2,434 unique French–Zimba verse pairs** from all
officially available portions: Mark, Luke, Galatians, Ephesians, Philippians,
1–2 Timothy, Titus, Philemon, 1–2 Peter, and 1–3 John.

The source is authentic and DRC-specific but copyrighted. Cached pages and
derived text remain local and Git-ignored.
