# Yombe (`yom`)

## Curation status

The open track contains **10,408 unique French--Yombe verse pairs** from the
complete available New Testament and Psalms coverage. The official source
identifies the language as Yombe/Kiyombe of the Democratic Republic of the
Congo and releases the work under CC BY-SA 4.0.

The preparation script reads the official eBible verse-per-line archives,
aligns canonical references with the public-domain French Louis Segond 1910,
normalizes Unicode and whitespace, and removes exact duplicate pairs.

- [Source and alignment metadata](metadata/ebible_alignment.md)
- [Reproducible preparation script](scripts/prepare_ebible.py)
- [Official Yombe source](https://ebible.org/Scriptures/details.php?id=yom)

The processed alignment is a derivative work. It omits the Biblica trademark,
states the formatting changes, attributes the original, and remains under the
same CC BY-SA 4.0 licence as required by the source terms.
