The Yombe edition contains the New Testament and Psalms. The alignment is a
formatting derivative: verse text is extracted, joined by reference, normalized
to Unicode NFC, whitespace-collapsed, and exact-pair deduplicated. No linguistic
content is intentionally altered.

Required attribution for derivatives is preserved: “The original work by
Biblica, Inc. is available for free at www.biblica.com and open.bible.” The
Biblica trademark is omitted from the derived dataset name, and the output is
distributed under CC BY-SA 4.0.

The installed package marks Yombe versions conservatively as copyrighted. The
official eBible source page provides the more specific licence for this exact
2002 open edition and is therefore the controlling source for this track.
