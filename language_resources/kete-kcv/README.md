# Kete (`kcv`)

This Kasai track is built from the official **Kete Bible Translation Project**
on YouVersion/Bible.com and aligned to the French Louis Segond 1910 by shared
verse identifiers.

It currently covers only the available portions from Mark and Luke, so it is
useful as a verified source trace but not yet large enough to satisfy the
project's 1,500-pair minimum on its own.

The source is authentic DRC scripture text but copyrighted, so cached pages and
derived text remain local and Git-ignored.
