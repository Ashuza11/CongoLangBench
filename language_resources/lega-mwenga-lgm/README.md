# Lega-Mwenga (`lgm`)

Lega-Mwenga is the first Maniema track, with **7,943 unique locally curated
French-aligned pairs**. This exact Lega variety remains
separate from Lega-Shabunda. Its authentic DRC text is restricted and therefore
kept local and Git-ignored.
