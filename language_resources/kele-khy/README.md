# Kele/Lokele (`khy`)

This Tshopo track contains **7,910 unique French--Kele/Lokele pairs** from the
1958 Kele/Lokele New Testament, aligned by shared
verse identifiers with the public-domain French Louis Segond 1910 edition.

The source is authentic but copyrighted. Raw and normalized text therefore
remains local and Git-ignored; the repository contains only reproducible
curation code and source metadata.
