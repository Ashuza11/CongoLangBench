# Ngbaka (`nga`)

The authentic DRC-labelled `WE NU GALE 1995` edition provides **29,977 unique
locally curated French-aligned pairs**. The package marks the Ngbaka edition as copyrighted, so
all text remains Git-ignored and is used only for local evaluation. This folder
publishes the preparation script and source metadata, not the text.

- [Source metadata](metadata/package_alignment.md)
- [Preparation script](scripts/prepare_package.py)
