# Logo / Logoti (`log`)

Logo is the second selected Northern DRC language. Two authentic DRC/South
Sudan package editions provide **9,649 unique locally curated French-aligned
pairs**. Both are marked copyrighted, so their text remains Git-ignored; metadata and the
preparation script are published.
