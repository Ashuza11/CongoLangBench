# African Languages Lab `multi-open`: English--Kikongo

- Configuration: `english-kikongo`
- Raw rows: 330,000
- Unique normalized non-empty pairs: 315,959
- Source file: `data/english-kikongo/train-00000.parquet`
- Local SHA-256: `370f42aaa909ca1d46bf81c06bacdb82831608a6486799e15d70f0ddd9dfc412`
- Columns: English, Kikongo, source/target token counts, automatic quality score
- Access: project owner accepted the gated dataset terms
- Licence field: `other`
- Retrieval date: 2026-08-23
- Intended project role: fifth Western DRC language track

The automatic `translation_quality_score` is generated by a model judge and is
not a human gold label. It is retained as metadata rather than used as proof of
translation correctness or as an automatic deletion rule. The normalized file
contains scores from 1 through 10 plus one missing score; every row remains
available for later stratified analysis.

The dataset card names the target language only as Kikongo. It does not provide
row-level country or subvariety provenance. Accordingly, this project uses ISO
`kon`, keeps the variety unspecified, and does not claim that every row is a
specific DRC Kikongo variety. Kituba (`ktu`) remains separate.
