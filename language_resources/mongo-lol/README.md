# Mongo / Nkundo (`lol`)

## Northwestern DRC track

Two authentic DRC-labelled Mongo editions provide **38,815 unique locally
curated French-aligned pairs** through the accepted Africa Corpus source. The package
marks both Mongo editions as copyrighted, so raw and normalized text remains
Git-ignored and may be used locally for evaluation only.

The repository publishes the reproducible preparation script, edition IDs,
counts, hashes, and access status—not the restricted text. If redistribution
permission or an independently open Mongo corpus becomes available, it can be
added as a separate publishable source.

- [Source and access metadata](metadata/package_alignment.md)
- [Local preparation script](scripts/prepare_package.py)
- [Africa Corpus catalogue](https://huggingface.co/datasets/AfriSpeech/africa-corpus)
