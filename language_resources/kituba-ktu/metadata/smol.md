# Google SMOL Kituba acquisition

- Dataset: [Google SMOL](https://huggingface.co/datasets/google/smol)
- Language: Kituba (DRC), `ktu`
- Licence: CC BY 4.0
- Retrieval date: 2026-08-21
- Raw sources: `smolsent/en_ktu.jsonl`, `smoldoc/en_ktu.jsonl`, and `gatitos/ktu_en.jsonl`

Raw file SHA-256 values:

- `ktu-en-smolsent.jsonl`: `9e45052b19da5944680099bf342fa6cd5c0356ac75e76bc1141e4286b59e739d`
- `ktu-en-smoldoc.jsonl`: `493262c3aa968d9041e59f773e80265490f5dfbde10853da9ec26be7baf5f9dd`
- `ktu-en-gatitos.jsonl`: `8b658e589b0b678c065758b3ecacacb9e0d71f00314828947ba0f930ba7dfe05`

The source provides 863 SmolSent pairs, 130 SmolDoc documents that can be flattened into aligned sentences, and a separate 2,417-row GATITOS lexicon. The lexicon is not counted as sentence bitext. SMOL documents a known quality warning for Kituba translations; that warning is retained on every processed sentence row rather than silently discarded.

After flattening the documents and deduplicating across the two sentence sources, the processed export contains 2,469 unique Kituba–English sentence pairs.

The processed sentence export is generated by [scripts/prepare_smol.py](../scripts/prepare_smol.py). Rows are marked `verified_source` because the dataset is authentic and CC BY 4.0, while `quality_flags` records the known source warning.
