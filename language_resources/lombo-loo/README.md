# Lombo (`loo`)

This Tshopo/Congo Basin transition track contains **1,812 unique pairs** from
the open Lombo translations of Mark and Luke aligned with the public-domain
French Louis Segond 1910 edition.

The Lombo documents are released under CC BY-SA 4.0. The generated bitext is
publishable under the same licence with the attribution recorded in
[source metadata](metadata/open_documents.md).
