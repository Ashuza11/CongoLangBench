# Maniema top five

Maniema is complete for the current curation phase. Every selected language is
spoken in the DRC, has explicit variety/provenance metadata, and exceeds the
minimum of 1,500 aligned units.

| Rank | Language | ISO | Pairs | Alignment | Repository handling |
|---:|---|---|---:|---|---|
| 1 | Lega-Mwenga | `lgm` | 7,943 | French, verse | restricted local |
| 2 | Lega-Shabunda | `lea` | 30,703 | French, verse | restricted local |
| 3 | Zimba | `zmb` | 2,434 | French, verse | restricted local |
| 4 | Bembe / Kibembe | `bmb` | 2,984 | French, paragraph | restricted local |
| 5 | Holoholo | `hoo` | 1,531 | French, verse | restricted local |

Lega-Mwenga and Lega-Shabunda are separate evaluation tracks and must never be
merged implicitly. All five sources are authentic but copyrighted, so Git
contains only scripts, provenance, counts, and integrity results.

## Acquisition backlog

- Kusu (`ksv`): identified resources are currently audio rather than aligned text.
- Bangubangu (`bnx`): the currently available official portion is below 1,500.
- Songola/Songoora (`sod`): the official Mark portion is below 1,500.
- Buyu (`byi`): all available Luke chapters yield 962 pairs; 538 more are needed.

The `africa-bitext-builder` catalogue helped identify several editions, but
Bangubangu, Buyu, Songola, Zimba, and Holoholo catalogue entries do not
currently resolve to downloadable package files. Official publisher sources
were therefore inspected directly, and only independently verified text was
counted.
