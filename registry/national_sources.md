# National-language source plan

This table is the starting point for Phase 1A. `pair_potential` is an estimate from the source documentation, not a validated count. A source becomes usable for the benchmark only after its exact language variety, alignment, licence, and data contents are checked.

Recommended order:

1. **Congo Swahili:** acquire the open CLEAR Global/Gamayun kits first because they already report more than the 1,500-pair target.
2. **Lingala:** acquire the CC BY-SA Biblica/Open.Bible USFM and align it with a compatible French edition.
3. **Kikongo ya Leta:** verify the SMOL components and request permission for scripture or other parallel sources.
4. **Ciluba:** inspect the gated multi-open resource and identify a permissioned/open sentence source; SMOL is currently mainly lexical support.

Do not count lexicons, catalogue pages, model cards, or generic Swahili/Kongo resources as national-language sentence bitext without row-level verification.
