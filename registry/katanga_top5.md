# Southeastern DRC / Katanga top five

The current bitext-feasible regional set is:

| Rank | Language | ISO 639-3 | Open pairs | Provenance status |
|---:|---|---:|---:|---|
| 1 | Luba-Katanga / Kiluba | `lub` | 197,411 | DRC track |
| 2 | Tabwa / Kitabwa | `tap` | 5,039 | DRC source |
| 3 | Bemba | `bem` | 381,259 | Zambia-labelled cross-border source |
| 4 | Aushi | `auh` | 1,900 | Zambia-labelled cross-border sources |
| 5 | Lunda | `lun` | 134,568 | Zambia-labelled cross-border source |

All five exceed the 1,500-pair minimum. Cross-border sources are retained with
explicit variety flags and should be compared with DRC usage before benchmark
freeze when qualified speakers or DRC-specific data are available.

Sanga/Kisanga (`sng`) was initially shortlisted because of its regional size,
but no redistributable bitext or OPUS corpus was found. The package contains no
`sng` edition, the public Door43 catalogue has no Sanga-language repository,
and the available Bible scans are copyrighted by the Trinitarian Bible
Society. Sanga therefore remains in the acquisition backlog rather than
occupying a current bitext-feasible slot. Never substitute Sango (`sag`).
