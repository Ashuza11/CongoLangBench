# Northern DRC top five

The active set requires Northern DRC relevance, authentic source provenance,
and at least 1,500 usable aligned pairs. Languages already assigned to another
regional top five are not counted again.

| Rank | Language | ISO | Curated bitext | Publication status |
|---:|---|---|---:|---|
| 1 | Zande / Pazande | `zne` | 30,865 French pairs | Local evaluation only; restricted text |
| 2 | Logo / Logoti | `log` | 9,649 French pairs | Local evaluation only; restricted text |
| 3 | Mayogo | `mdm` | 7,911 French pairs | Local evaluation only; restricted text |
| 4 | Budu | `buu` | 17,387 French pairs | Local evaluation only; restricted text |
| 5 | Ndo / Kebu | `ndp` | 7,943 French pairs | Local evaluation only; restricted text |

All five exceed the minimum. Their authentic package sources are marked
copyrighted, so raw and processed text remains local and Git-ignored. The
repository publishes source metadata, hashes, counts, preparation scripts, and
permitted future evaluation results.

Ngbaka Ma'bo (`nbm`) and Mangbetu (`mdj`) are major Northern DRC priorities but
remain acquisition backlogs because no usable sentence bitext was found across
the audited open corpora or package. Northern Ngbandi is excluded here because
it already replaced Lingala in the Northwestern Congo Basin top five.
