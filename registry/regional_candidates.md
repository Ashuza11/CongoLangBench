# Regional candidate selection

`regional_candidates.csv` is a planning shortlist, not an acquired-data list. The ranks are initial priorities based on the regional information supplied for this project. A candidate becomes an active track only after:

1. a usable bilingual text source is located;
2. the exact language variety and ISO code are verified;
3. DRC provenance is confirmed where the language crosses borders; and
4. the source licence or permission allows the intended research use.

The shortlist intentionally includes languages already present in the repository. Those existing tracks will be reused during the national/regional phases and later expanded during the dedicated Kivu phase.
